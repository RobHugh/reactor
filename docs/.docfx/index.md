# ReactorSockets API reference

Generated by DocFX from the XML documentation comments in the source. Only the public surface
appears here: L0 and L1 are `internal` and are not part of the contract. Every type lives in the
<xref:ReactorSockets> namespace, except the `ReactorSockets.Logging` package's Sink in
<xref:ReactorSockets.Logging>.

Each profile is a Reactor driven by one synchronous `Pump()` on the consumer's own thread, with
`Drain()` yielding that Pump's Events.

## Datagram Session profile

Sessions over UDP, addressed as Peers, with four delivery modes.

| --- | --- |
