Which field of a DiagnosticRecord's tagged subject is populated (ADR 0013). A record has exactly one subject, so a Sink or formatter switches on this rather than checking several optional fields for which one is set.

public enum DiagnosticSubjectKind

Fields

None = 0

The record concerns no particular Link or Source.

Link = 1

The record concerns a registered Link, carried in Link.

Source = 2

The record concerns an unauthenticated claimed origin, carried in Source.

Peer = 3

The record concerns an established Peer, carried in Peer. Distinct from Source: a Peer exists only once a handshake has completed, while a Source is merely a claimed origin — a refusal made before a Peer exists tags Source, never this.
