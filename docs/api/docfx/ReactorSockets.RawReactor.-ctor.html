Constructs a Reactor bound to the calling thread (ADR 0002) — every future mutating call must come from this same thread or it throws.

public RawReactor(ReactorOptions options, int? scratchBufferSize = null)

Parameters

options ReactorOptions

The shared options value. Every knob on it is validated here, and ArenaSize is resolved against this profile's floor; a combination that cannot work throws at construction and nowhere else.

scratchBufferSize int?

The single scratch buffer every Link's receive lands in, reused across Links since only one is read at any instant inside a single-threaded Pump (ADR 0012). Defaults to MaxUdpDatagramSize. Provenance: the largest payload a UDP datagram can carry over IPv4, at which an IPv4 datagram cannot be truncated. An IPv6 datagram of 65 508 to 65 527 bytes exceeds it and is reported as truncated. This is the profile-specific knob a consumer lowers to opt into truncation, kept off ReactorOptions because it has no meaning outside Raw's datagram surface. It must be at least 1 and at most MaxLength minus 1, because the scratch allocation adds one truncation byte. A value outside that range throws ArgumentOutOfRangeException.

Remarks

The memory bill is one scratch buffer plus one arena — scratchBufferSize + 1 + ArenaSize (the extra byte is how a truncated datagram is recognised) — neither multiplied by capacity, because Raw holds nothing for a Link across a Pump. That is what "invents nothing on the wire" looks like from the constructor (ADR 0012).
