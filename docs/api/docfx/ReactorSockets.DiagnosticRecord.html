A single diagnostic emitted to an IReactorDiagnostics Sink: a closed DiagnosticId, its fixed DiagnosticLevel, a tagged subject — none, Link, Source or Peer (ADR 0013) — and two numeric slots whose meaning is documented per DiagnosticId member. No strings, no object[], no closures — everything here lives on the stack and is built only after IsEnabled(DiagnosticLevel) passes.

Methods

ForAdmissionCapReached(int, int)

Builds a AdmissionCapReached record. No subject. declined counts declinings where the work waits out of reach and pieces of work where the Reactor held it — see the remarks on AdmissionCapReached.

ForArenaExhausted(LinkId, int, int)

Builds an ArenaExhausted record for the Link that made the request.

ForArenaExhausted(PeerId, int, int)

Builds an ArenaExhausted record for the Peer whose Message could not be reserved — the Session profile's counterpart to the Link-subject overload above (ADR 0014: share-holder identity is per-Peer in a Session, not per-socket).

ForCapacityExhausted(int, int)

Builds a CapacityExhausted record. No subject. declined is counted exactly as ForAdmissionCapReached(int, int)'s is.

ForCookieRejected(Source, long, long)

Builds a CookieRejected record for the claimed Source, carrying the epoch the cookie offered and the epoch current when it was checked.

ForDataAfterGoodbye(PeerId)

Builds a DataAfterGoodbye record for the Peer that kept sending after its own Goodbye. No claimed length: Value0 and Value1 are unused.

ForDatagramMalformed(Source, int)

Builds a DatagramMalformed record for the claimed Source, carrying the number of bytes that arrived.

ForDatagramTruncated(Source, int)

Builds a DatagramTruncated record for the claimed Source, carrying the scratch buffer size the datagram was truncated to.

ForDeliveryCounterRefused(PeerId, long, long)

Builds a DeliveryCounterRefused record for the Peer whose delivery-counter record claimed more Messages than this end ever sent it. Value0 is the claimed cumulative count; Value1 is the count of Messages this end has actually appended to this Peer's retention.

ForDestinationUnreachable(LinkId, SocketError)

Builds a DestinationUnreachable record carrying the platform SocketError reported for the send.

ForLingerNegotiated(PeerId, long, long)

Builds a LingerNegotiated record for the newly established peer. Value0 is this end's own Linger in milliseconds; Value1 is the effective (minimum of the two ends') Linger in milliseconds.

ForLinkFailed(LinkId, SocketError)

Builds a LinkFailed record carrying the platform SocketError that caused the failure.

ForMalformedFraming(PeerId, long, long)

Builds a MalformedFraming record for the Peer whose framing broke this profile's rules. Value0 is the offending length prefix — 0 for a truncation, where no full prefix was ever read; Value1 is this Reactor's own MaxMessageSize.

ForPeerRefusedCapacity(Source, int)

Builds a PeerRefused record for the claimed Source of a stream dialler refused because every capacity Slot was occupied. Value0 carries this Reactor's capacity; Value1 is unused.

ForPeerRefusedVersion(Source, long, long)

Builds a PeerRefused record for the claimed Source of a stream dialler refused because it announced a version this Reactor does not speak. Value0 is the version offered; Value1 is the version this Reactor requires.

ForRedialAttempted(PeerId, long, long)

Builds a RedialAttempted record for the Peer beginning a fresh re-dial attempt. Value0 is the attempt number; Value1 is the delay in milliseconds this attempt actually waited before dialling — the jittered figure, not the computed delay before jitter.

ForRedialFailed(PeerId, SocketError, long)

Builds a RedialFailed record for the Peer whose re-dial attempt could not connect. Value0 carries the platform SocketError as its underlying integer value; Value1 is the attempt number that failed.

ForResumeMatched(PeerId, long)

Builds a ResumeMatched record for the Peer a valid resume secret was matched back onto. Value0 is the number of retained outbound bytes the match rewound; Value1 is unused.

ForResumeUnmatched(Source, long, long)

Builds a ResumeUnmatched record for the claimed Source of a connection that claimed an existing Session and was refused rather than resumed. Value0 is the number of Interrupted Peers the claim was checked against; Value1 is the wire record type the claim arrived as.

ForVersionRefused(Source, long, long)

Builds a VersionRefused record for the claimed Source, carrying the version offered and the version this Reactor requires.
