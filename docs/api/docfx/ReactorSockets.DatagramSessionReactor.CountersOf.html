CountersOf(PeerId)

A point-in-time snapshot of one Peer's counters (ADR 0013). Throws if the Peer is not open, matching CountersOf(PeerId)'s shape for the stream profile — the datagram profile had no per-Peer counter reader until this member. OutOfWindowPackets and DuplicatePackets now reflect what the four per-Space receive windows have refused; UnreliableLossPackets reflects gaps either unreliable Space's window has slid past. MessagesReceived counts whole Messages handed to the frame arena for delivery, and not a Message the arena refused. Resumes counts the Peer's resumes: once per PeerResumed raised for it, and never reset by one (ADR 0013). The accepting end raises it when a matching Resume or a well-formed data Datagram from the exact address and port it sends to moves the Peer out of Interrupted. The dialling end raises it when it hears its session again after sending a Resume. RetentionHighWaterBytes reads the true per-Peer figure — summed across both reliable Spaces — from ReactorSockets.DatagramSessionReactor._retention.
