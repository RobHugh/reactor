The escape hatch (ADR 0007): a consumer registers UDP sockets at runtime, gets a LinkId back for each, and advances everything with a single synchronous Pump() call from their own loop. Nothing is delivered except in response to a call the consumer made, on the thread that constructed this Reactor. TCP joins the datagram surface here: a listening Link and the connections it accepts are registered and admitted the same way, and a stream Link's reads drain as SegmentReceived and EndOfStream exactly like a datagram Link's. A stream Link's Send(LinkId, ReadOnlySpan<byte>) takes what the socket will take and reports the count, arming exactly one Writable when it took fewer bytes than offered; Shutdown(LinkId) sends this Link's own FIN while it stays open for reading.

Remarks

How a bad LinkId is reported. A member that already returns a Result reports it as a failed Result: the channel exists, and a Link closing under a caller is an ordinary race rather than a programmer error, so SendTo(LinkId, Source, ReadOnlySpan<byte>), Send(LinkId, ReadOnlySpan<byte>) and Shutdown(LinkId) never throw for one. A member that returns data has no such channel — LocalOf(LinkId), RemoteOf(LinkId) and CountersOf(LinkId) would have to invent a sentinel or widen every call site into an unwrap — so they throw ArgumentException instead, whether the LinkId does not address an open Link at all, or it does but the Link is the wrong kind to answer the question (RemoteOf(LinkId) on a datagram or listening Link — the same wrong-kind case Send(LinkId, ReadOnlySpan<byte>), SendTo(LinkId, Source, ReadOnlySpan<byte>) and Shutdown(LinkId) report as a failed Result instead, because they can). Close(LinkId) is neither: it is idempotent by design, so a stale LinkId is simply a no-op.

Which members check the calling thread. Every member that mutates this Reactor or its sockets enforces the constructing-thread rule (ADR 0002): Pump(), Bind(IPEndPoint), SendTo(LinkId, Source, ReadOnlySpan<byte>), Send(LinkId, ReadOnlySpan<byte>), Shutdown(LinkId), Close(LinkId) and Dispose(). The pure reads — LocalOf(LinkId), RemoteOf(LinkId), CountersOf(LinkId) and Counters — deliberately do not, because each only copies out a value that the Reactor never mutates in place.

That is not a claim that they are safe to call concurrently with a Pump. The counters behind Counters and CountersOf(LinkId) are plain fields incremented without a barrier, so a reader on another thread has no guarantee of freshness and may observe a snapshot whose fields come from either side of a Pump. What it will not observe is a half-written value or a disposed socket. Treat a cross-thread counter read as a sample, not as a consistent cut; a consumer that needs one should read from its own Pump thread between Pumps.

Methods

Bind(IPEndPoint)

Binds a new UDP socket to endpoint and returns the LinkId that addresses it. Raw registers its transports at runtime, unlike a Session Reactor which declares its endpoints at construction (ADR 0014).

Close(LinkId)

Closes link and queues exactly one Closed event carrying LocalClose. A no-op if link does not address an open Link. The slot's generation advances, so a stale copy of link can never address whatever binds into this slot next (ADR 0014).

Connect(IPEndPoint)

Begins dialling a new outbound TCP connection to endpoint and returns the LinkId that addresses it immediately — connecting is advanced by the consumer's own loop like everything else, so this call never blocks and the handshake's outcome arrives later, from whichever Pump() first finds it resolved. A dial that succeeds produces exactly one Connected; a dial that fails produces a Closed naming Refused or Unreachable (or Failed for anything else), alongside a LinkFailed carrying the platform SocketError. Nothing about a dial in progress is delivered except in response to a Pump.

CountersOf(LinkId)

A point-in-time snapshot of one Link's counters (ADR 0013). Throws if the Link is not open.

Dispose()

Closes every Link still open and releases its socket. A Reactor owns every socket it bound, so a consumer that drops one without disposing it leaks those sockets until the finalizer each Socket carries runs. No Closed events are queued: nothing can drain a disposed Reactor. Idempotent; every other member throws ObjectDisposedException afterwards.

Drain()

Drains every event produced this Frame — since the last Pump() — in the order it was produced. Every drained RawEvent's Payload is valid only until the next Pump().

Listen(IPEndPoint)

Binds and listens on a new TCP socket at endpoint, returning the LinkId that addresses it. A listening socket is a Link like any other — one identity type, one lifecycle, one Closed event — because "Listener" is a role a Link plays for a consumer, not a kind of thing this library names (ADR 0008). It consumes a capacity slot exactly like any other Link, but holds no read share: accepting reads nothing into the frame arena (ADR 0014).

LocalOf(LinkId)

Returns the bound address of link. Link state, constant for the Link's lifetime, and therefore not event data (ADR 0014). Throws ArgumentException if link does not address an open Link.

Pump()

One synchronous advance: wipes the previous Frame's events and arena, then runs the readiness dispatch that reads whatever registered Link is ready right now. Throws InvalidOperationException if called from any thread other than the one that constructed this Reactor, or from inside a Pump already in progress.

RemoteOf(LinkId)

Returns the remote address of the stream Link link — Link state, constant for the Link's lifetime and therefore not event data, which is exactly why Accepted carries no address (ADR 0014). Illegal on a datagram or listening Link, since neither has a single remote for its whole lifetime the way a stream connection does — a bound UDP socket answers many senders, and a listening socket answers none. Throws ArgumentException if link does not address an open Link, or does but is the wrong kind, for the reason given on this type's own remarks: a member that returns data has no Result channel to report a wrong-kind call through instead.

Send(LinkId, ReadOnlySpan<byte>)

Send is stream-only and illegal on a datagram or listening Link. Takes what the socket will accept of payload right now and reports the count — never blocks, never copies and never queues (ADR 0008): whatever the socket did not take stays with the caller, who decides whether and when to offer it again. Queuing was rejected on principle, not merely left out: an unbounded queue is a memory leak with a network cause, and a bounded one needs a limit this library would have to justify plus a way to learn when to retry — which reintroduces this same event under another name. Either way the Reactor would be inventing a per-Link FIFO policy, which is machinery a Session has and Raw was said not to lend.

SendTo(LinkId, Source, ReadOnlySpan<byte>)

Sends payload to destination in one datagram, all-or-nothing (ADR 0008). Fails without throwing when link does not address an open Link or the send itself fails.

Shutdown(LinkId)

Shutdown is stream-only and illegal on a datagram or listening Link. Sends this Link's own FIN, closing the send half while the Link stays open for reading — this is what lets a consumer build a request-response protocol that signals end-of-request by closing the write half, and it is a one-way door: a further Send(LinkId, ReadOnlySpan<byte>) on this Link fails afterwards. Fails without throwing (ADR 0008), naming whichever applies: link does not address an open Link, or it does and that Link cannot be shut down. The open check comes first, for the reason on Send(LinkId, ReadOnlySpan<byte>).
