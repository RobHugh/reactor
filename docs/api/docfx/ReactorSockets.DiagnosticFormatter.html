The one authoritative rendering of a DiagnosticRecord to text (ADR 0005, ADR 0013), so a structured Sink consumes the typed fields and never formats, and a text Sink gets this library's wording rather than inventing its own. Holds no state: nothing is allocated until Format(in DiagnosticRecord) is called, and a consumer who never formats pays nothing.

Remarks

The output is permanent public surface — consumers grep it, alert on it and paste it into issues — and its shape is {Level} {Id} ({number}), {subject}: {what happened} ({value slots}), the subject segment omitted when the record has none. Numbers are rendered in the invariant culture.

A Source is rendered as a claim — claimed source 203.0.113.7:4242 (unauthenticated) — never as a fact like "from 203.0.113.7:4242". A Source is a hint about origin that an attacker chooses, and the wording must not invite a consumer to firewall on it (CONTEXT.md, ADR 0013).

Methods

Format(in DiagnosticRecord)

Renders record to text, leaving the record untouched. Throws ArgumentOutOfRangeException for an id or subject kind outside the roster, which only a default or hand-forged record can carry — every record the library builds has a cause by construction.
