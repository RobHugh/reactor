The Diagnostic Sink contract. Implementations are called synchronously, on the consumer's thread, inside Pump — a Sink that stalls stalls the Frame, and a Sink that throws is caught, counted as SinkFaulted, and disabled for the life of the Reactor (ADR 0005). Calling back into the Reactor from a Sink is a programmer error and throws.
