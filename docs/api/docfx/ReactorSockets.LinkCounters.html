A point-in-time snapshot of one Link's counters (ADR 0013): monotonic figures running from that Link's registration, with no reset, fetched by value and keyed by LinkId — there is no accessor that enumerates every Link's counters in one call.

Remarks

There is no read-share figure here, unlike PeerCounters. The Raw profile reads a ready Link once per Pump, so a Link never reaches a second reservation in one Frame and its read share can never be exhausted. A field that could only ever read zero fails ADR 0013's counter test.

Bytes delivered from this Link into the Arena. Not derivable: no other figure attributes received bytes to one Link, and the Arena high-water is a per-Frame peak rather than a running total.

BytesSent

Bytes the transport accepted for sending on this Link. Not derivable: the Reactor-scope datagram figures count datagrams rather than bytes, cover every Link at once, and never see a stream Link.
