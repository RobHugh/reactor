Pump()

One synchronous advance: records this call's arrival against the last one (ReactorSockets.StreamSessionReactor.ObservedPumpInterval) before anything else, then wipes the previous Frame's events — which is also the moment a Peer still PeerClosing only because the last Frame's Messages had not been drained past yet becomes eligible to close (ReactorSockets.StreamSessionReactor.RetryPeersPendingClose()) — then admits ready connections, advances every in-flight dial and reads whatever bound socket is ready right now, running the handshake for everything that arrived. Every Peer whose received count advanced somewhere in that work — this Frame's own reads, or a held-back Message finally delivered by ReactorSockets.StreamSessionReactor.RetryPeersWithBufferedMessages() — then has its delivery counter emitted exactly once (ReactorSockets.StreamSessionReactor.EmitDeliveryCounters()), before every Peer's queued retention bytes are flushed exactly once (ReactorSockets.StreamSessionReactor.FlushPendingRetentionWrites()) regardless of how many Send(PeerId, ReadOnlySpan<byte>) calls queued them. Finally, every established Peer's two independent idle timers are enforced in one scan (ReactorSockets.StreamSessionReactor.EnforceIdleTimers()): a Peer from which nothing has been received for ReactorSockets.StreamSessionReactor.PeerSlot.RemoteSendIdleInterval × ResolvedMissedHeartbeats moves to PeerInterrupted, an already-Interrupted Peer instead closes with LingerExpired once its effective Linger has elapsed since the interruption, and every surviving Peer that has written nothing to the wire — including whatever this Frame's own flush just carried — for at least SendIdleInterval sends the same delivery-counter record as a heartbeat, unconditionally and regardless of whether anything was ever received from it. Once idle timers may have closed an Interrupted Peer on Linger expiry, every Interrupted Peer this Reactor itself dialled is given its re-dial attempt for this Frame (ReactorSockets.StreamSessionReactor.ProcessRedials()) — a schedule derived from the observed Pump interval just recorded above and the effective Linger, never a separate attempt-count knob, so a Peer whose Linger closed it this same Frame is never also given one. Throws InvalidOperationException if called from any thread other than the one that constructed this Reactor, or from inside a Pump already in progress.
