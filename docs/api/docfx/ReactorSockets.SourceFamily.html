The address family of a Source, carried as an explicit tag rather than inferred from the address bytes (ADR 0014). With DualMode never set, nothing in a 16-byte field distinguishes a zero-padded IPv4 address from an IPv6 one.

Fields

An IPv6 address, occupying all 16 bytes of AddressBytes.
