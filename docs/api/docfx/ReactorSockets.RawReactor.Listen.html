Listen(IPEndPoint)

Binds and listens on a new TCP socket at endpoint, returning the LinkId that addresses it. A listening socket is a Link like any other — one identity type, one lifecycle, one Closed event — because "Listener" is a role a Link plays for a consumer, not a kind of thing this library names (ADR 0008). It consumes a capacity slot exactly like any other Link, but holds no read share: accepting reads nothing into the frame arena (ADR 0014).

Remarks

Inbound connections are admitted by whichever Pump() finds this Link ready, bounded by the shared admission cap (ResolvedAdmissionCap) every accept and handshake in this library draws from. Beyond the cap, a pending connection is left exactly where it was — in the OS backlog — for a later Pump to admit; Raw invents nothing on the wire, so it says nothing to a remote waiting past the cap (ADR 0007). Binding rules are unchanged from Bind(IPEndPoint): exclusive, no dual-mode, no hostname, no configure callback.
