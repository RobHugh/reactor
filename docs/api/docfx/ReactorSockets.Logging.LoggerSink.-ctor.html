LoggerSink(ILogger)

An IReactorDiagnostics Sink that writes each record to an ILogger. The message is Format(in DiagnosticRecord)'s text, never wording of this package's own, and the state carries the record's typed fields for a structured provider. One type serves every profile: install one per Reactor, each over a logger with its own category from one ILoggerFactory, and every Reactor writes one stream with each record attributed by category.

Remarks

This Sink is bound by the same contract as any other (ADR 0005): the Reactor calls it synchronously, on the thread that called Pump, inside the Frame. Every provider the ILogger is wired to runs there too, so a provider that writes to a console or a file synchronously stalls the Frame for as long as the write takes. Configure providers that hand the write off and return.

The category is the attribution. A record with a Link or Peer subject also names its Reactor in the Reactor field and the message, but a record with no subject or a Source subject names none, so one instance shared between Reactors leaves those unattributed.
