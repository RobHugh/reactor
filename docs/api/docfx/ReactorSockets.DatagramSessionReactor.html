The datagram Session profile (ADR 0009): Sessions established over UDP, addressed as Peers, driven by a single synchronous Pump() from the consumer's own loop. This slice builds the handshake and everything that guards it — the stateless cookie, the amplification bound, version and capacity refusals, session identity and demultiplexing. It does not yet carry data; the packet records, the four sequence Spaces, fragmentation and the acknowledgement machinery land in the slices that follow, and SessionEventKind grows with them.

Remarks

Endpoints are declared, not registered. Unlike RawReactor, which hands back a LinkId for every socket a consumer registers, this Reactor takes its endpoints on Endpoints at construction and never rebinds (ADR 0014). Binding returns no identity because there is nothing to address: a consumer addresses Peers, and a Peer is not a socket. A Reactor that declares no endpoints binds nothing until its first Connect(IPEndPoint), which binds one wildcard, port-zero socket in the destination's address family and appends it to BoundEndpoints.

Capacity counts Peers. The bound sockets are not share-holders and hold no read share (ADR 0014): a Peer's Messages arrive through whichever socket happens to carry them, so charging the arena per socket would give one Peer on a single-socket Reactor the whole arena and sixty-four Peers a sixty-fourth each — exactly inverted. The read share is the arena divided by Capacity, and it belongs to the Peer.

What a stranger can make this Reactor do. Very little, and that is the design. Anything an unauthenticated remote can generate at will goes to the Diagnostic Sink and never to the event stream, so a stranger cannot write into the consumer's protocol. Every reply to an unverified sender is exactly one control datagram of ReactorSockets.Session.DatagramSessionProtocol.ControlDatagramSize bytes, answering exactly one control datagram of the same size, so bytes sent never exceed bytes received and this Reactor cannot be used to amplify a flood at a spoofed third party. A bare Hello is answered with a Cookie whatever it claimed — never a Refusal — so nothing about this Reactor's version or occupancy is learnable without first proving the ability to receive at the address claimed.

The wire session id is not an authenticator. It is a receiver-assigned random 32-bit demultiplexing token: unguessable enough that an off-path attacker cannot address a Session it was never introduced to, and nothing more. This library does not encrypt, does not authenticate the data plane, and an on-path attacker who can read a datagram can forge one. Consumers needing confidentiality or integrity must layer it themselves.

Constructors

DatagramSessionReactor(DatagramSessionOptions)

Constructs a Reactor bound to the calling thread (ADR 0002) — every future mutating call must come from this same thread or it throws — and binds every declared endpoint in the order supplied. A bind that fails throws here, naming the endpoint: binding is part of what this Reactor is, so there is no half-bound Reactor to hand back and no DiagnosticId member for the failure.

Properties

BoundEndpoints

The endpoints this Reactor is bound to right now, in the order they were declared, with any socket bound by a dial appended. A snapshot: it answers what is bound, and there is no member that binds another.

Counters

A point-in-time snapshot of this Reactor's own counters (ADR 0013). No reset.

Methods

Close(PeerId)

Ends the Session with peer and queues a PeerClosed carrying LocalClose. Idempotent: a stale PeerId is a no-op, because a Peer closing under a caller is an ordinary race rather than a programmer error.

Connect(IPEndPoint)

Begins a Session with destination, returning the PeerId that will address it. The Peer occupies a capacity Slot from this moment, exactly as a dialling Link does in RawReactor: the handshake is work this Reactor is holding, and pretending otherwise would let a consumer dial past capacity and discover it only on the far side of a round trip. PeerConnected or PeerClosed resolves it on a later Pump.

Dispose()

Releases every socket this Reactor bound. A Reactor owns every socket it bound, so a consumer that drops one without disposing it leaks those sockets until each Socket's finalizer runs. No PeerClosed events are queued: nothing can drain a disposed Reactor. Idempotent; every other member throws ObjectDisposedException afterwards.

Drain()

Drains every event produced this Frame — since the last Pump() — in the order it was produced.

Pump()

One synchronous advance: wipes the previous Frame's events and arena, then reads whatever bound socket is ready right now, running the handshake for everything that arrived. Throws InvalidOperationException if called from any thread other than the one that constructed this Reactor, or from inside a Pump already in progress.
