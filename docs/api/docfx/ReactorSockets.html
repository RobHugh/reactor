Classes

DatagramSessionOptions

The construction surface of a DatagramSessionReactor (ADR 0012): the shared L0 budget composed in as Reactor, plus the knobs this profile alone has. Composed rather than inherited, so that nothing protocol-specific here can ever leak into ReactorOptions and turn it into the base class ADR 0011 refused.

DatagramSessionReactor

The datagram Session profile (ADR 0009): Sessions established over UDP, addressed as Peers, driven by a single synchronous Pump() from the consumer's own loop. It carries the handshake and everything that guards it — the stateless cookie, the amplification bound, version and capacity refusals, session identity and demultiplexing — and the data plane behind it: packet records in four sequence Spaces, one per DeliveryMode, fragmentation of reliable Messages, acknowledgement and retransmission, heartbeats, Goodbye, interruption and Resume.

DiagnosticFormatter

The one authoritative rendering of a DiagnosticRecord to text (ADR 0005, ADR 0013), so a structured Sink consumes the typed fields and never formats, and a text Sink gets this library's wording rather than inventing its own. Holds no state: nothing is allocated until Format(in DiagnosticRecord) is called, and a consumer who never formats pays nothing.

RawReactor

The escape hatch (ADR 0007): a consumer registers UDP sockets at runtime, gets a LinkId back for each, and advances everything with a single synchronous Pump() call from their own loop. Nothing is delivered except in response to a call the consumer made, on the thread that constructed this Reactor. TCP joins the datagram surface here: a listening Link and the connections it accepts are registered and admitted the same way, and a stream Link's reads drain as SegmentReceived and EndOfStream exactly like a datagram Link's. A stream Link's Send(LinkId, ReadOnlySpan<byte>) takes what the socket will take and reports the count, arming exactly one Writable when it took fewer bytes than offered; Shutdown(LinkId) sends this Link's own FIN while it stays open for reading.

ReactorOptions

The budget L0 spends inside a Pump, shared by every profile. Composed as a member into each profile's options type rather than inherited from a base (ADR 0012) — nothing protocol-specific may ever enter this type, since a knob two of three profiles need is exactly what would turn it into the base class ADR 0011 refused.

StreamSessionOptions

The construction surface of a StreamSessionReactor (ADR 0011): the shared L0 budget composed in as Reactor, plus the knobs this profile alone has. Composed rather than inherited, so that nothing protocol-specific here can ever leak into ReactorOptions and turn it into the base class ADR 0011 refused.

StreamSessionReactor

The stream Session profile (ADR 0010): Sessions established over TCP, addressed as Peers, delivering u32 length-prefixed Messages rather than the byte runs the transport gives. Construction validates StreamSessionOptions and its allocation bill and binds the declared endpoint set; each Peer is carried through the handshake to an established Session. Each established Peer reassembles Messages in its own persistent receive buffer and delivers each whole one as a MessageReceived event copied into the shared frame arena.

Structs

DiagnosticRecord

A single diagnostic emitted to an IReactorDiagnostics Sink: a closed DiagnosticId, its fixed DiagnosticLevel, a tagged subject — none, Link, Source or Peer (ADR 0013) — and two numeric slots whose meaning is documented per DiagnosticId member. No strings, no object[], no closures — everything here lives on the stack and is built only after IsEnabled(DiagnosticLevel) passes.

LinkCounters

A point-in-time snapshot of one Link's counters (ADR 0013): monotonic figures running from that Link's registration, with no reset, fetched by value and keyed by LinkId — there is no accessor that enumerates every Link's counters in one call.

LinkId

A Link's identity: the Reactor that issued it, a zero-based slot index, and a generation counter that increments when the slot is reused, so a stale LinkId held past a Link's close compares unequal to whatever now occupies that slot (ADR 0014) rather than aliasing it.

PeerCounters

A point-in-time snapshot of one Peer's counters (ADR 0013): monotonic figures running from that Peer's establishment, with no reset, fetched by value and keyed by PeerId — mirrors LinkCounters's Raw-profile shape and the same "no accessor enumerates every Peer's counters in one call" rule.

PeerId

A Peer's identity inside this process: the Reactor that issued it, a zero-based Slot index, and a generation counter that increments when the Slot is reused, so a stale PeerId held past a Peer's close compares unequal to whatever now occupies that Slot (ADR 0007) rather than aliasing it. Shared by both Session profiles (ADR 0010), exactly as LinkId is the Raw profile's.

RawEvent

One event drained from a RawReactor. A ref struct because Payload aliases the frame arena directly and must never outlive the Frame it was drained in (ADR 0008). Kind determines exactly which other fields are populated — the kinds are DatagramReceived, Closed, Accepted, Connected, SegmentReceived, EndOfStream and Writable — the complete Raw profile roster.

RawEventEnumerator

The zero-allocation enumerator Drain() returns. A ref struct so that a foreach over it can yield RawEvent — itself a ref struct — without a heap-allocated IEnumerator<T>, following the same pattern as Span<T>'s own enumerator.

ReactorCounters

A point-in-time snapshot of the Reactor-scope counters (ADR 0013): monotonic figures running from construction, with no reset. Fetched by value so nothing lets a consumer hold a pointer into live state across a Pump; diffing two snapshots gives everything a reset would, from state the consumer already owns.

Result

The outcome of an operation whose failures are the caller's to check rather than the runtime's to throw — a wrong-kind call on a Link (Send on a datagram Link) or a send the remote end or the network refused. Error names the illegality or the platform failure in prose; there is no error code enumeration here because, unlike CloseReason, nothing about this failure needs to survive as permanent public API — a consumer branches on IsSuccess and logs or surfaces Error as-is.

SendResult

The outcome of one Send(LinkId, ReadOnlySpan<byte>) call. Unlike Result, a stream send has a quantity worth reporting even on success: the Reactor holds no outbound bytes (ADR 0008), so Send takes what the socket will take right now and hands back the count — the caller keeps whatever was not taken, and BytesSent is how it learns how much that is.

SessionEvent

One event drained from a Session Reactor. A ref struct because Payload aliases the frame arena directly, and must never outlive the Frame it was drained in (ADR 0008). Kind determines exactly which other fields are populated.

SessionEventEnumerator

The zero-allocation enumerator every Session Reactor's Drain returns (ADR 0010), shared by both profiles via ReactorSockets.ISessionEventSource rather than duplicated per profile. A ref struct so that a foreach over it can yield SessionEvent — itself a ref struct — without a heap-allocated IEnumerator<T>, following the same pattern as Span<T>'s own enumerator.

Source

Who a datagram claims to be from — an unauthenticated hint about origin, never an identity (ADR 0014). Carried on the record path as a value type: { family, 16 address bytes, scope id, port }, roughly 56 bytes, so a Diagnostic or an Event never allocates to name a Source.

Interfaces

IReactorDiagnostics

The Diagnostic Sink contract. Implementations are called synchronously, on the consumer's thread, inside Pump — a Sink that stalls stalls the Frame, and a Sink that throws is caught, counted as SinkFaulted, and disabled for the life of the Reactor (ADR 0005). Calling back into the Reactor from a Sink is a programmer error and throws.

Enums

CloseReason

Why a Link closed, defined and kept stable by this library rather than borrowed from a platform enumeration (ADR 0008): a consumer's permanent logic switches on this instead of a SocketError that differs between Windows and Unix. The exact SocketError travels in the DiagnosticRecord emitted at the same moment, linked to this only by the Link and the Pump it happened in.

DeliveryMode

Which of a datagram Session's four delivery modes carries a Message sent through Send(PeerId, DeliveryMode, ReadOnlySpan<byte>) (ADR 0009). See docs/delivery-modes.md for the consumer-facing guide to choosing one and the full guarantees each mode makes: ordering, duplicate suppression, and what a late arrival does. Each mode is carried in its own Space.

DiagnosticId

A closed, permanent enumeration of diagnostic causes with explicit values in reserved blocks — common 1-99, Raw 100-199, datagram session 200-299, stream session 300-399 (ADR 0013) — so a future insertion cannot silently renumber an id a consumer has persisted. There is no None or Unknown member and zero is never used: every DiagnosticRecord has a cause by construction.

DiagnosticLevel

The minimum severity a IReactorDiagnostics Sink was installed to receive. Ordered by ascending severity so that a level is enabled when it is at least as severe as the installed MinimumLevel.

DiagnosticSubjectKind

Which field of a DiagnosticRecord's tagged subject is populated (ADR 0013). A record has exactly one subject, so a Sink or formatter switches on this rather than checking several optional fields for which one is set.

DisconnectReason

Why a Peer's Session ended, defined and kept stable by this library rather than borrowed from a platform enumeration. Deliberately not shared with the Raw profile's CloseReason (ADR 0008): most of the members a Session needs are protocol vocabulary Raw can never produce, and a single shared enumeration would leave one profile documenting members it cannot emit.

RawEventKind

Which kind of RawEvent a drained event is (ADR 0008). Accepted comes from a listening Link, Connected from dialling, SegmentReceived and EndOfStream from stream reads, and Writable from partial sends.

SendOutcome

The outcome of one Send(PeerId, ReadOnlySpan<byte>) call. A bare enum rather than a result struct (unlike SendResult): a Session-level send has no partial-completion quantity worth reporting back — the framed Message either fit in the Peer's retention region whole, or it did not, so the outcome is the whole story.

SessionEventKind

Which kind of SessionEvent was drained, and therefore which of its fields carry meaning. Shared by both Session profiles (ADR 0010).

SourceFamily

The address family of a Source, carried as an explicit tag rather than inferred from the address bytes (ADR 0014). With DualMode never set, nothing in a 16-byte field distinguishes a zero-padded IPv4 address from an IPv6 one.
