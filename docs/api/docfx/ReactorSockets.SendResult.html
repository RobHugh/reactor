The outcome of one Send(LinkId, ReadOnlySpan<byte>) call. Unlike Result, a stream send has a quantity worth reporting even on success: the Reactor holds no outbound bytes (ADR 0008), so Send takes what the socket will take right now and hands back the count — the caller keeps whatever was not taken, and BytesSent is how it learns how much that is.

Properties

BytesSent

The number of bytes the socket actually took this call. Zero when IsSuccess is false. Never queued or copied by the Reactor — whatever this does not account for out of the offered payload is still the caller's to keep and retry.

Error

The failure reason, or null when IsSuccess is true.

IsSuccess

Whether the call itself succeeded — not whether every offered byte was taken. A short send (BytesSent less than what was offered) is still true: it arms exactly one Writable for this Link and is otherwise ordinary. This is false only for an illegal call (wrong Link kind, a stale LinkId, a Link already shut down for writing) or a socket-level failure.
