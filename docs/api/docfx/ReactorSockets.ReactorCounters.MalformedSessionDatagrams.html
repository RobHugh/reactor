MalformedSessionDatagrams

Data datagrams thrown away for failing to parse after their session id named a live Session: a short or bad header, a record that does not read, an illegal Fragment set. Kept apart from UnknownSourceDatagrams because the two say different things about who is sending — this traffic did name a Peer, so it is either an established Peer sending bytes this Reactor cannot read or a forgery that guessed a live id, where the other figure is traffic that named nobody at all. Reactor-scope like its neighbour rather than per-Peer: a datagram whose body did not parse is not proven to have come from the Peer whose id it carries, and charging it there would let a stranger move an established Peer's figures. Moves only on the datagram Session profile, and its Diagnostic is the same DatagramMalformed. Not derivable: the Peer it names never counts it, and UnknownSourceDatagrams counts only traffic that named nobody.
