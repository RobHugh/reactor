UnreliableQueueBytes

The most bytes one Peer may have queued for Unreliable and UnreliableSequenced until a Pump writes them, counting each Message's payload plus its 7-byte record header. A Send that would go past it returns SendQueueFull. null means RetentionSlots × (ResolvedFragmentSize + 7): as many full unreliable Messages as one reliable Space retains Fragments. Provenance: derived from RetentionBytes and FragmentSize, so the unreliable queue holds as much as a reliable Space does. Must be at least ResolvedFragmentSize + 7, one full unreliable Message.

Remarks

The queue is preallocated, UnreliableQueueBudgetBytes in total, so an unreliable Send allocates nothing. A Pump writes up to one maximum UDP payload's worth of Datagrams per Peer, so a budget above about 65 507 bytes takes more than one Pump to drain.
