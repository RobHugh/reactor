ArenaSize

The frame arena's size in bytes. Left unset, a Reactor defaults it to its own profile floor. Provenance: derived from the profile — one maximum deliverable unit, since below it that unit could never be delivered, and only the profile's constructor knows what it must exceed (ADR 0012). A value below that floor throws at construction, naming the arithmetic. A value above MaxLength throws ArgumentOutOfRangeException at construction, because the arena is one array and the runtime cannot allocate a larger one.
