Source(SourceFamily, UInt128, long, int)

Who a datagram claims to be from — an unauthenticated hint about origin, never an identity (ADR 0014). Carried on the record path as a value type: { family, 16 address bytes, scope id, port }, roughly 56 bytes, so a Diagnostic or an Event never allocates to name a Source.

Remarks

Equality is total and exact over every field, including ScopeId: an IPv6 link-local address is only meaningful with its zone index, and two hosts reachable at the same fe80::/10 address on different interfaces must not compare equal — the datagram profile keys a cookie HMAC over this value. Family is an explicit tag rather than inferred from AddressBytes, because with DualMode never set there is nothing in a 16-byte field distinguishing a zero-padded IPv4 address from an IPv6 one.
