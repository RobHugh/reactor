One event drained from a RawReactor. A ref struct because Payload aliases the frame arena directly and must never outlive the Frame it was drained in (ADR 0008). Kind determines exactly which other fields are populated — this slice implements DatagramReceived, Closed, Accepted, Connected, SegmentReceived, EndOfStream and Writable — the complete Raw profile roster.

Properties

Kind

Which kind of event this is.

Link

The Link this event concerns. Always populated — for Accepted this is the new connection's identity, not the listening Link's (see ListeningLink for that).

ListeningLink

The listening Link that produced this accepted connection. Populated only when Kind is Accepted; a consumer listening on several Links needs this to know which one just fired. Named for the Link rather than a "Listener" deliberately: listening is a role a Link plays, not a kind of thing this library names.

Payload

The received bytes, valid only until the next Pump(). Populated when Kind is DatagramReceived or SegmentReceived. For a Segment this is exactly the run of bytes that arrived on this Link in this Frame — no claim of being a whole anything, and nothing is held across a Pump to make one (ADR 0008).

Reason

Why the Link closed. Populated only when Kind is Closed.

Source

Who claims to have sent this datagram — an unauthenticated hint, never an identity. Populated only when Kind is DatagramReceived.
