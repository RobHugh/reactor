Remarks

A knob carries a default only when that default is derived — from machinery this library owns, from another knob, or from a citable standard. A value that trades the consumer's own resources against their own traffic, and that nothing in this library can derive, is required with no default: MaxMessageSize, RetentionBytes, SendIdleInterval and Linger are all of that kind, and so is Capacity. Guessing any of them would be guessing at the consumer's application.

Values fixed by the wire format are not here at all and cannot be reached from here: the 32-bit acknowledgement width, the 64-entry duplicate window, the four sequence Spaces, zero as the reserved session id, the 20-byte data header and the thirty-second cookie epoch are protocol constants. Changing one changes what a datagram means, which is a version, not a setting.

The memory bill. A Reactor built from these options preallocates, and the whole of it is these two lines:

  • receive: Capacity × 2 × ReceiveWindowFragments × FragmentSize — two of the four Spaces are reliable and reassemble, and each holds a window of whole fragment slots per Peer.
  • send: Capacity × 2 × RetentionBytes — the same two Spaces retain what they have sent until it is acknowledged, per Peer.

The frame arena (ArenaSize) is over and above those two lines and is shared across the whole Reactor rather than multiplied by capacity. Every check below is deterministic and entirely the caller's, so failures throw at construction — ArgumentOutOfRangeException for a single bad value and ArgumentException for a combination that cannot work — rather than being reported through a Result.

Properties

Endpoints

The endpoints to bind at construction, in the order supplied; possibly empty. Declared once and never rebound (ADR 0014) — a Session's addresses are part of what it is, not something it acquires later. An empty set binds nothing until the first dial, which binds a single wildcard, port-zero socket in the destination's address family.

Entropy

The entropy the cookie secrets, session ids and resume secrets are drawn from. A construction knob in ADR 0012's sense — the consumer's own resource, and a consumer with a hardware source or a policy about which generator may be used is entitled to supply it. It carries a default only because that default is derived rather than guessed: the platform's own CSPRNG is the citable provenance.

FragmentSize

The bytes a fragment carries, and therefore the unit every buffer here is measured in. Defaults to 1200 — QUIC's floor beneath the 1280-byte IPv6 minimum MTU — which is the one value with citable provenance for surviving an arbitrary path. Must lie between 576 (RFC 791's guaranteed reassembly minimum) and 65 507 (the maximum UDP payload).

Linger

How long a closing Session stays alive to retransmit its Goodbye and absorb what is still in flight. Required, for the same reason as SendIdleInterval: it trades a prompt teardown against a clean one.

MaxMessageSize

The largest Message, in bytes, this Reactor will accept or deliver. Required: it is a statement about the consumer's own protocol that nothing here can derive. It is also the frame arena's floor — an arena that cannot hold one maximum Message could never deliver one.

MissedHeartbeats

How many consecutive heartbeat intervals may pass in silence before a Peer is declared gone. Defaults to 3, RFC 4271's hold-time multiple. Must be at least 2, because a count of 1 makes a single lost datagram fatal and no network is that reliable.

Reactor

The shared L0 budget: capacity, admission cap, arena size, time source and Diagnostic Sink. Required — a Reactor cannot be built without one, and its Capacity has no default of its own.

ReceiveBudgetBytes

The receive line of the memory bill in bytes, as a long so that a combination too large to allocate is a value this can report rather than an overflow it silently wraps through.

ReceiveWindowFloor

The resolved receive window: ReceiveWindowFragments if set, otherwise the fragments one maximum Message occupies.

ReceiveWindowFragments

The fragments each reliable Space may have outstanding per Peer. Defaults to exactly the number a maximum Message occupies, which is ADR 0004's deadlock floor rather than a performance choice: a window narrower than one whole Message can never deliver one, so it can never advance, so the sender can never send the rest.

ResolvedFragmentSize

The resolved fragment size: FragmentSize if set, otherwise 1200.

ResolvedMissedHeartbeats

The resolved missed-heartbeat count: MissedHeartbeats if set, otherwise 3.

ResolvedReceiveWindowFragments

The resolved receive window: ReceiveWindowFragments if set, otherwise ReceiveWindowFloor.

RetentionBytes

The bytes each reliable Space retains per Peer for retransmission, until what it holds is acknowledged. Required: this is the consumer trading their memory against their tolerance for stalling on loss, and the right answer depends on their traffic, not on anything here.

SendBudgetBytes

The send line of the memory bill in bytes, reported the same way.

SendIdleInterval

How long a Session may go without sending before it sends a heartbeat instead. Required: shorter costs bandwidth on an idle link, longer costs time to notice a dead Peer, and only the consumer knows which they would rather spend.
