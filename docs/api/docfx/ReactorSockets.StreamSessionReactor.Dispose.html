Dispose()

Releases every socket this Reactor bound or accepted. A Reactor owns every socket it bound, so a consumer that drops one without disposing it leaks those sockets until each Socket's finalizer runs. No PeerClosed events are queued: nothing can drain a disposed Reactor. Idempotent; every other member throws ObjectDisposedException afterwards.

public void Dispose()

Remarks

Entropy is deliberately not disposed. It may be a source the consumer holds and uses elsewhere, and a Reactor disposing a value it was merely handed would be reaching outside what it owns.
