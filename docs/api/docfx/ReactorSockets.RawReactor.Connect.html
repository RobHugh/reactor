Connect(IPEndPoint)

Begins dialling a new outbound TCP connection to endpoint and returns the LinkId that addresses it immediately — connecting is advanced by the consumer's own loop like everything else, so this call never blocks and the handshake's outcome arrives later, from whichever Pump() first finds it resolved. A dial that succeeds produces exactly one Connected; a dial that fails produces a Closed naming Refused or Unreachable (or Failed for anything else), alongside a LinkFailed carrying the platform SocketError. Nothing about a dial in progress is delivered except in response to a Pump.

Remarks

There is no hostname overload and no connect-timeout knob: nothing ticks unless the consumer Pumps, and a dial going nowhere is closed by the consumer or by the OS, not by a timer this library invented. The dialled Link consumes a capacity slot exactly like a Bind or a Listen; LocalOf(LinkId) answers the address TCP bound implicitly the moment the connect began, whether or not the handshake has finished.
