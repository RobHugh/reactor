Dispose()

Closes every Link still open and releases its socket. A Reactor owns every socket it bound, so a consumer that drops one without disposing it leaks those sockets until the finalizer each Socket carries runs. No Closed events are queued: nothing can drain a disposed Reactor. Idempotent; every other member throws ObjectDisposedException afterwards.

public void Dispose()

Remarks

There is deliberately no finalizer here. This type holds nothing unmanaged of its own — the sockets do, and each already finalizes itself — so a finalizer would add a GC cost to every Reactor to duplicate a guarantee the runtime already makes.
