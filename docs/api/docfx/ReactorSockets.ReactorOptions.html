Remarks

A knob carries a default only when that default is derived — from machinery the library owns, from another knob, or from a citable standard (ADR 0011, ADR 0012). Capacity has no such derivation and is therefore required, with no default. Construction throws ArgumentOutOfRangeException for a single bad value and ArgumentException for a combination that cannot work, because every check here is deterministic and entirely the caller's — unlike Send, whose failures belong to the remote end or the network and are reported through a Result instead.

Every per-Pump cost a remote party can inflate is bounded at construction (ADR 0012). Reading is bounded by each share-holder's share of the arena — ArenaSize divided by Capacity, with one whole unit always allowed — and accepts and handshakes are both bounded by AdmissionCap. Three mechanisms with one reason, and the checklist for anything added later: a cost a remote party can raise inside one Pump, on the consumer's thread, needs a bound fixed here, because the failure is invisible until someone points a load generator at it. The datagram profile adds a fourth on its own options, MaxDatagramsPerPump, because the arena share does not see control traffic.

Properties

AdmissionCap

The per-Pump bound on accepts and handshakes alike. Defaults to Capacity. Provenance: derived from Capacity — one Pump never spends more admission work than a full Reactor's worth, and the remainder waits in the OS backlog or is dropped (ADR 0012).

ArenaSize

The frame arena's size in bytes. Left unset, a Reactor defaults it to its own profile floor. Provenance: derived from the profile — one maximum deliverable unit, since below it that unit could never be delivered, and only the profile's constructor knows what it must exceed (ADR 0012). A value below that floor throws at construction, naming the arithmetic.

Capacity

The number of share-holders this Reactor admits — Links in Raw, Peers in a Session (ADR 0014) — and the multiplier on every preallocation. Required; there is no default derivable from anything the library owns (ADR 0011, superseding ADR 0001's "default 64"). Must be at least 1.

MinimumLevel

The minimum DiagnosticLevel the installed Sink receives. Must be supplied together with Sink — neither carries a default, since a default level would be a guess at how much diagnostic volume the consumer wants. Provenance: absent only alongside an absent Sink, where no level can matter (ADR 0012).

ResolvedAdmissionCap

The resolved admission cap: AdmissionCap if set, otherwise Capacity.

Sink

The Diagnostic Sink records are sent to, or null to disable diagnostics entirely. Must be supplied together with MinimumLevel — both present or both absent. Provenance: absent means off, which is derived rather than chosen — with no Sink there is nowhere for a record to go, so no level can matter (ADR 0012).

TimeProvider

The source of monotonic time for every duration this library measures. Defaults to System; only GetTimestamp/GetElapsedTime are ever consulted, never GetUtcNow. Provenance: the framework's own clock, and the only requirement on it is that reads be monotonic, which GetTimestamp is (ADR 0012).
