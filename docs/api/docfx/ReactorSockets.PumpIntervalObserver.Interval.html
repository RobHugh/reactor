Interval

The interval between the two most recent Observe() calls.

public TimeSpan Interval { get; }

Property Value

TimeSpan

Remarks

Before a second call this reads MaxValue — deliberately, and documented rather than left to fall out of a default. There is no cadence to report yet, and the one thing this value is for is flooring ReactorSockets.Session.RedialSchedule's first computed delay (Math.Min(pumpInterval, linger)): reporting the largest possible interval defers entirely to that schedule's own ceiling, the effective Linger, rather than inventing a cadence that has never actually been observed. Zero would have done the opposite — floor every delay at immediately, the one value ReactorSockets.Session.RedialSchedule's own constructor already refuses to accept.
